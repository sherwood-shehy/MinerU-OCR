## 发现并拦截的版面问题

构造的合并表头样本中，Layout 1.28.2 将横跨两列的表头输出为两个普通表头单元格。若直接调用默认 `find_tables()`，它也会使用同一版面模型，错误地得到一致结果。

本版改为独立的 `find_tables(use_layout=False)` 核验：该样本在正式交付前被拒绝，原始候选与质量报告保留。强制本地模式停止；自动模式允许回退 MinerU。已有后处理仍对正确提取的复杂 HTML 表格保持原结构。此检查不保证表格线检测自身毫无遗漏；无框线或歧义表格可能保守地回退云端。

## 复现与边界

推荐安装：`python -m pip install -e ".[test,local]"`。执行 `doctor`、`preflight INPUT.pdf`，再用 `process INPUT.pdf --engine local --output-dir DELIVERY --work-dir RECORDS` 验证无上传路径。测试日志、预检 JSON、摘页、成功素材包和被拒绝候选保存在本机 `_agent/tmp/v041/`，由 Git 忽略；用户原 PDF 未提交。

页序、字符/数值与表格不变量检查不是人工准确率验收，不证明所有字词、阅读顺序、公式和语义完全正确。继续抽查复杂表格、技术图、公式和附录边界；视觉语义提炼仍留给下游。
