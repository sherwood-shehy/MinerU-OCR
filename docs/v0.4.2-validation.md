## 边界与兼容性

- 表格筛查复用固定版本 Layout 的图像分割模型，通过窄适配器调用其随包组件。升级 Layout 时须重新验证此适配器；没有打包模型到 skill。
- 模型表格区域分数门槛为 0.7，疑似图片表格另使用多行多列文字排列信号。分数并非经过校准的概率；很小、低分、复杂续表或无合并的多层表头可能漏检。
- 首行全为非空文字的规则 td 表采用首行表头约定，并在内部记录 textual_first_row_convention。此约定不证明原文确有语义表头；有疑问时保留 HTML 或原页确认。
- 后处理不自动恢复漏字、漏行或丢失的合并关系。复杂表格保留 HTML并抽查；云端结果也不是免检结果。
- 包版本、CLI 与全局 skill 均同步到 0.4.2。源码 skill 与本机全局 skill 的六个文件逐一 SHA-256 核对，技能校验器通过。
